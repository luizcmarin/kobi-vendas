# Kobi Vendas

O Kobi Vendas é um aplicativo web instalável para o parceiro revendedor dos produtos Kobi: a
apresentação, o folder, o site, o guia de venda, as mensagens e os posts de cada produto, com o
nome e o WhatsApp do parceiro.

Acesse a versão publicada em <https://luizcmarin.github.io/kobi-vendas/>.

## Características

- funciona offline depois do primeiro carregamento, com o material inteiro dentro;
- pode ser instalado como aplicativo no navegador;
- não exige uma conta, e não fala com servidor nenhum.

## Privacidade e dados

Os dados do parceiro (nome, revenda, cidade e WhatsApp) ficam no armazenamento local do navegador.
Eles não são enviados a este repositório nem a lugar nenhum, e saem do aparelho só na mensagem ou
no folder que o parceiro manda.

Limpar os dados do navegador, remover a instalação ou trocar de aparelho apaga esses dados, e eles
precisam ser preenchidos de novo.
